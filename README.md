# 에듀집 등록 서류 스킬 (Claude Code용)

교사가 직접 만든 웹앱을 **에듀집(에듀테크 정보체험 플랫폼)**에 등록할 때 필요한 서류를 Claude Code가 만들어 주는 스킬입니다.

## 무엇을 해 주나요

- **개인정보 처리방침 페이지** (`/privacy`): 앱 코드를 직접 읽고, 실제로 수집·처리하는 정보에 맞춰 씁니다.
- **필수기준 체크리스트**: 공식 「학습지원 소프트웨어 필수기준 체크리스트(공급자용)」 형식이며, 증빙 칸에 방침 조 번호를 맞춰 넣습니다.
- **화면 고지 정비**: AI 사용 고지(인공지능기본법 제31조), 가입 동의, 저작권 표시, 이용 안내 페이지
- **소개 문단**: 구글 폼 "내용" 칸에 붙여넣을 글
- **PDF 생성**: 크롬으로 제출용 PDF를 만듭니다.

구글 폼 제출은 하지 않습니다. 제출은 선생님이 직접 하세요.

## 설치

[Claude Code](https://claude.com/claude-code)가 설치되어 있어야 합니다.

```bash
git clone https://github.com/woghks0524/edujip-register-skill.git ~/.claude/skills/edujip-register-generic
```

업데이트할 때:

```bash
git -C ~/.claude/skills/edujip-register-generic pull
```

## 사용법

앱 프로젝트 폴더에서 Claude Code를 열고 이렇게 말하면 됩니다.

> 에듀집에 등록할 서류 만들어줘

처음에 다음 네 가지를 물어봅니다.

- 공급자명 (실명)
- 문의처 (전화, 이메일)
- 제출 서류를 보관할 폴더
- 앱 배포 주소

## 알아 두세요

- 사업자 등록이 없는 교사 개인은 에듀집에 기업 회원으로 가입하는 대신 **구글 폼**으로 제출합니다. 폼 주소는 [SKILL.md](SKILL.md)에 있습니다.
- 개인정보 동의서는 공식 HWP 양식으로 직접 작성하는 경우가 많아서, 스킬이 따로 만들지 않고 먼저 물어봅니다.
- 법령 내용(인공지능기본법 시행령 등)은 2026년 10월 기준입니다. 스킬이 작업할 때 최신판을 한 번 더 검색해 확인합니다.
- 이 스킬로 만든 서류의 최종 검토와 책임은 제출하는 선생님께 있습니다.
